# NEXORA — 3D Premium Website

A responsive, 3D-inspired brand website for NEXORA Mini Energy Bar.

## Upload / update on GitHub
1. Extract the ZIP.
2. In the `nexora-website` GitHub repository, upload the contents of this folder to the repository root.
3. Keep the `assets` folder structure intact.
4. Commit the changes to the `main` branch.
5. GitHub Pages will redeploy automatically if Pages is enabled.

## Important business information
The website deliberately does not invent product ingredients, nutrition claims, certifications, pack size, customer reviews, or a selling price. The product price currently says "Ask for price" until the real price is confirmed.

The pack artwork is a CSS visual concept, not a photograph of the actual product.

## Current functionality
- Responsive brand website
- 3D-style animated product illustration using CSS
- Emotional brand storytelling
- Product enquiry link to the provided Facebook page
- SEO metadata, mobile navigation, scroll reveal animations
- No paid libraries or build process

## Not included yet
This is not a full online checkout system. It does not process payments, manage inventory, or store customer orders. A real checkout requires verified product data and a secure order/payment backend.
